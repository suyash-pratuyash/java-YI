# Java-YI

A minimal Java project that prints `Hello World` to the console.

## Project structure

```text
java-YI/
├── src/
│   └── com/
│       └── hello/
│           └── HelloWorld.java
└── README.md
```

## Prerequisites

- Java Development Kit (JDK) 8 or newer
- A terminal or command prompt

## Run the application

From the project root, compile and run the program:

```bash
javac src/com/hello/HelloWorld.java
java -cp src com.hello.HelloWorld
```

Expected output:

```text
Hello World
```

## Notes

This repository currently contains a simple starter Java program and is suitable as a base for learning Java project structure and command-line execution.
